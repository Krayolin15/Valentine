💖 Will You Be My Valentine?

A cute, playful, and interactive Valentine’s Day webpage built with pure HTML, CSS, and JavaScript.
Designed to be fun, responsive, and a little mischievous 😄

This project is perfect for sharing with someone special — the “No” button fights back, while the “Yes” button slowly takes over until love wins.

✨ Features

💝 Cute animated GIFs to set the mood

📱 Fully responsive design (mobile & desktop friendly)

😈 Interactive “No” button with escalating phrases

💚 “Yes” button grows every time “No” is clicked

🎉 Success animation when “Yes” is selected

🧠 Clean, readable, beginner-friendly JavaScript

🚀 Single-file project — no setup needed

🛠️ Built With

HTML5 – Structure

CSS3 – Styling, animations & responsiveness

Vanilla JavaScript – Button logic & interactions

No frameworks. No libraries. Just clean code.

📂 Project Structure
index.html


Everything (HTML, CSS, JS) is contained in one single file for simplicity and easy sharing.

▶️ How to Use

Download or clone the repository

Open index.html in any modern browser

Send it to your Valentine 💌

Watch what happens when they try to say “No” 😉

💡 How It Works (Quick Overview)

Clicking No:

Changes the button text using a predefined phrase list

Increases the size of the Yes button

Clicking Yes:

Replaces the GIF

Shows a success message

Hides both buttons

All logic is handled with simple DOM manipulation
